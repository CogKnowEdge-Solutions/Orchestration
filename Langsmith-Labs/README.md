# LangSmith Labs

A collection of hands-on labs for learning LangSmith, covering beginner to advanced topics.

## Structure

- `Lab1-Beginner/tracing-basics/` - Tracing Basics & Types of Runs (Beginner)

## Getting Started

Each lab is a Jupyter notebook with step-by-step instructions and exercises.

## Requirements

- Python 3.x
- Jupyter Notebook
- LangSmith account (for API key)
